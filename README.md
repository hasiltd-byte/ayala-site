# אילה דקל — אתר סופרת

אתר סטטי בעברית וב־RTL. קבצי האתר המוכנים נמצאים ב־`dist/`.

תצוגה מקומית: `node server.cjs`, ואז http://127.0.0.1:4173.

האתר כולל קטלוג עם סינון, תקצירים וקישורי חנות; אודות; נושאי מפגשים; קישורי מאמרים; שאלות נפוצות; ויצירת קשר דרך עמוד הפייסבוק המקושר בוויקיפדיה. נושאי המפגשים הם הצעת עריכה המבוססת על תחומי העיסוק המתועדים, ואינם לוח אירועים או התחייבות לשירות זמין. אין טופס שאוסף מידע ואין נתונים מומצאים של המלצות או מכירות.

SEO: HTML מלא, lang ו־dir, כותרת ותיאור, canonical, Open Graph, נתוני Person/WebSite/Book/ItemList מובנים, robots.txt ו־sitemap.xml. בהעברה לדומיין ציבורי יש להחליף את כתובת Sites ב־HTML ובקובצי robots ו־sitemap. האתר ב־Sites מתחיל פרטי; אינדוקס ציבורי מחייב פרסום ציבורי. דירוג חיפוש אינו מובטח על ידי בדיקת Lighthouse.

Lighthouse מקומי לנייד, 8 באוקטובר 2026: ביצועים 100, נגישות 100, Best Practices 100, SEO 100. LCP כ־1.2 שניות, CLS 0. הדוחות המלאים נשמרו ב־`.qa/mobile.json`. תנאי אחסון ובדיקה חיצונית עשויים לשנות את התוצאות. נבדקו גם 1440, 768 ו־390 פיקסלים, תפריט נייד, סינון, פתיחת תקצירים, תמונות ושגיאות דפדפן.

מקורות: https://he.wikipedia.org/wiki/אילה_דקל ; https://heb.hartman.org.il/person/ayala-dekel/ ; https://www.e-vrit.co.il/Author/13421/ . צילום מאתר מכון הרטמן ועטיפות מאתר עברית, עם קרדיט בתחתית. לפני שימוש מסחרי יש לוודא זכויות שימוש בתצלום ובעטיפות. הטקסט נוסח מחדש. אין אנליטיקה או עוגיות מעקב באתר.
